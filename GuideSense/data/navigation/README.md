# Navigation data

- `seongdong-crosswalks.csv`: 사용자 제공 원본, CP949, 987행, 기준일 2022-12-15. [공공데이터 출처](https://www.data.go.kr/data/15111354/fileData.do), 이용허락범위 제한 없음(포털 표기). 원본 값 보존.
- `seongdong.geojson`: southkorea/seoul-maps JUSO 2015 시군구 데이터에서 성동구 Feature만 추출. [원본](https://github.com/southkorea/seoul-maps/blob/dbb1dcde2e3c9937684c5a44ab9301888ad63ee6/juso/2015/json/seoul_municipalities_geo.json). 저장소 라이선스 Apache-2.0. 변경: 성동구 추출 및 JSON 직렬화. 저작자 Lucy Park 및 원본 기여자.
- 경계는 2015년 데모 지역 판별용이며 최신 행정구역 인증 자료가 아니다. 시설 데이터의 전체 공간 범위나 현재 작동을 보증하지 않는다.
