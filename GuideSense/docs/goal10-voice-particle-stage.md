# Voice particle stage — 2026-10-09

사용자 요청: 출발·도착 입력란 없이 음성 버튼으로 시작. 버튼 주변 파티클이 구름처럼 일렁이고, 목적지가 확정되면 지도가 S커브로 올라온 뒤 아래 움직임 데이터가 등장한다.

## 구현
- 초기 화면은 음성 버튼과 최소 안내만 표시. 수동 위치 입력 제거.
- 현재 위치 + 음성 목적지 확정 시 경로 자동 조회. 같은 장소 재선택 중복 조회 방지, 기존 요청 취소 유지.
- 파티클 1,080개를 비대칭 덩어리로 겹친 Canvas. 연결 상태에 따라 움직임 강도 변경. 실제 음량 측정 시각화는 아니다.
- 지도 1.2초 cubic-bezier(.76,0,.24,1), 데이터 260ms 지연. 음성 컴포넌트는 전환 중 유지.
- reduced-motion에서는 정적인 입자/즉시 화면 전환. 숨겨진 탭 RAF 중지, unmount 정리, DPR 최대 2.
- 경로 비교 근거는 접힌 상세 영역. 휴대폰 실시간/공개 Replay 출처와 데이터 의미 유지.
- 음성 서버 지침도 버튼 안내에서 자동 조회 안내로 수정하고 기존 8000 서버 재시작.

## 검증
- 단위 테스트 46개, 음성 API 테스트 21개 통과.
- 실제 브라우저에서 초기 화면의 입력란 제거와 파티클 렌더 확인.
- 음성 브라우저 테스트는 합성 위치·WebRTC 이벤트를 사용하며 실제 마이크 음성을 OpenAI로 전송한 검증은 아니다.
- 화면: artifacts/navigation-live/voice-particle-stage.png
- 타입 검사와 최신 프로덕션 빌드 통과.
- 브라우저 전체 27개 통과 후, 화면 정착 스크린샷·초기 늦은 응답 취소 관련 4개 통과(고유 시나리오 총 28개).
- 1440/1280/320px, 자동 조회 중복 방지, 애니메이션/정적 접근성 설정, 실제 Canvas 변화, Replay와 센서 연결 회귀 확인.
