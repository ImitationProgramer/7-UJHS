# Goal 6 — 공개 행동 Replay와 경로 미리보기 연결

2026-10-09. 사용자 확정 입력: **공개 Replay**. 실제 안내견 센서/GPS 연결은 이번 범위가 아니다.

## 사용자 흐름

1. 지도·검색에서 출발지와 도착지를 선택하고 길찾기를 실행한다.
2. 평가 가능한 후보를 선택한 뒤 지도 미리보기의 **개 행동 데이터 연결**을 켠다.
3. 기본 기록은 Dog45의 연속 30초(걷기→앉기). Dog22 걷기 기록 및 Dog44의 분류 불일치 사례도 선택할 수 있다.
4. **동행 재생**을 누르면 기존 `/ws/replay`가 저장된 6축 IMU를 기존 RandomForest로 재추론한다. 재생 진행률이 가상 경로의 위치를 움직인다.
5. 연속된 유효 분석 구간의 예측 클래스가 달라지면 지도 번호 마커와 **경로 위 행동 기록**을 표시한다. 해당 가상 위치에서 가장 가까운 경로상 횡단 시설까지 거리를 함께 표시한다.
6. 완료 후 **기록 저장**으로 출처·모델·경로·분석 결과가 포함된 JSON을 내려받을 수 있다.

## 연결 방식과 의미

- 실제 AI 역할: 기존 모델의 112개 센서 특징 기반 6개 활동 분류. 원본 annotation은 모델 입력으로 전달하지 않고 결과 비교용으로 표시한다.
- 경로 대응: `(prediction.window_end - manifest.start) / (manifest.end - manifest.start)`를 실제 경로 선형 길이에 곱한다. 예측이 도착한 브라우저 시각은 위치에 사용하지 않는다.
- 현재 지도 위치는 Replay의 진행률을 사용한다. 30초 공개 기록을 경로 전체에 대응시키는 시연이며 실제 보행 속도나 GPS 이력이 아니다.
- 변화 탐지: 인접 window ID, 같은 run/route, 양쪽 모두 유효한 예측일 때 클래스 차이를 기록한다. 무효 구간 또는 수신 누락 이후는 변화로 연결하지 않는다.
- ‘앉기’ 분류를 멈칫·통증·위험 감지로 바꾸지 않는다. 변화 이유와 시설 사이 인과관계도 추정하지 않는다.
- 가상 기록은 시설 경로 추천 점수·가중치에 반영하지 않는다. 향후 실제 위치가 있는 센서 기록을 수집·검증한 뒤 개인화 경로 판단을 별도로 설계해야 한다.

## 상태와 보관

클라이언트 메모리에 현재 실행의 분석 기록만 보관한다. 새로고침, 경로 변경, 동행 모드 해제, 재시작, 연결 끊김/오류 시 제거한다. 서버 DB나 localStorage에 위치 이력을 자동 저장하지 않는다. JSON 다운로드는 사용자가 누를 때만 실행한다.

각 Replay WebSocket은 독립 session이다. 길찾기에서 사용해도 `/diagnostics`의 Replay나 iPhone LIVE 상태를 수정하지 않는다. 기존 모델·프로토콜·추론 서버는 변경하지 않았다.

재시작 명령 후에는 새로운 run ID가 확인될 때까지 이전 snapshot을 무시한다. 상태가 COMPLETED여도 마지막 prediction은 처리한다. Dog45의 마지막 Sitting 추론은 30.2초에 처음 도착하며 snapshot 진행률·elapsed는 30초로 제한되므로 이 처리가 필요하다.

기록 파일에는 `source=canine_dataset_replay`, `isLive=false`, `association=simulated_by_replay_progress_not_recorded_GPS`, `usage=demonstration_only_excluded_from_route_ranking`를 포함한다. 데이터 출처·라이선스·변경 사항·모델 버전을 manifest 그대로 보존한다.

## 구현 소유 경계

- `navigation/companion.ts`: 시간→가상 경로 대응, 분석 기록과 변화 판정.
- `navigation/CompanionJourney.tsx`: 기존 Replay hook 연결, 제어·출처·기록 다운로드와 로그.
- `NavigationPanel.tsx`: 경로만 재생 / 행동 연결 전환과 진행률 공유.
- `NavigationMap.tsx`: 변화 번호 마커 및 커지는 미리보기를 고려한 지도 framing.
- 기존 센서/Replay/모델 코드와 TMAP 판정·가중치는 보존.

## 검증

팀 공유 아카이브에서 필요한 모델·Replay 14개 파일만 복원했다. 원본 2GB CSV 및 개인 단말 캡처는 복원하지 않았다. 모델 checksum·23개 실제 재추론 결과는 `goal6-replay-restoration.md` 참조.

- 순수 연결 로직 10개 단위 테스트: 시간 기준, 좌표 보간, 중복/역순, 최종 응답, 무효/누락 구간, 오분류 보존.
- 새 브라우저 연결 테스트 2개: 실제 모델 추론 + 명시적 합성 경로 fixtures. 동기 재생/일시정지, 10개 구간, 최종 변화 1개, JSON 내용, 초기화, 오분류 및 320px/axe 확인.
- 기존 센서·Replay를 포함한 전체 브라우저 테스트 **13개 모두 통과**. 전체 Vitest **33개 통과**, 전체 workspace TypeScript와 production build 통과.
- 실제 TMAP 왕십리역→한양대학교병원 경로와 실제 공개 Replay를 연결한 수동 브라우저 검증. 위치 대응 자체는 가상이다.

## 남겨둔 범위

실제 안내견의 센서·GPS 동기화, 멈칫/급정지/회전 탐지 정의, 건강 판단, 개인화 선호도, 실제 이력 기반 재추천, 장기 저장, 음성·카메라는 구현하지 않았다. 이번 연결은 **실제 공개 센서값의 AI 분류가 경로 맥락과 함께 표시되는 동작**을 검증한다.

실제 API 연결 스크린샷: `artifacts/navigation-live/companion-desktop.jpg`, `companion-mobile.jpg`. 실제 Dog45의 최종 분석 10개/분류 변화 1개를 확인했다.

## 동행 카드의 움직임 그래프

팀원 진단 화면의 `MotionGraph`를 길찾기 동행 카드에 재사용한다. 별도 WebSocket을 만들지 않고 `CompanionJourney`가 이미 사용하는 `useReplay.history`(최근15초·최대750샘플)를 전달한다. 가속도·각속도의 벡터 크기, 현재3초 구간 음영, 자동 눈금과 단위 미확인 표기를 유지한다. 재생·정지·기록 변경·연결 끊김 때 지도와 같은 상태를 따르며 초기화 중 이전 기록은 숨긴다. 이는 공개 기록 Replay이며 실시간 하드웨어 수신으로 표시하지 않는다.

검증: 실제 저장 모델/Replay E2E2개 통과. 두 그래프 생성·유효 데이터 선형·일시정지 시 값 고정·재시작 초기화·320px 가로 넘침·axe 접근성을 확인했다. 타입 검사 및 프로덕션 빌드 통과.
