# 휴대폰 실시간 센서 연결

길찾기 → 개 행동 데이터 연결 → 연결할 데이터 ‘휴대폰 실시간 센서’가 기본값이다. 기존 Expo 앱의 `/ws/device` → FastAPI → `/ws/dashboard` 파이프라인을 사용한다. 최신 실제 프레임을 10Hz 화면 갱신으로 최근15초·150개까지만 보관하며 파일에 저장하지 않는다. 가속도 g, 각속도 rad/s 그래프·기기ID·연결 상태를 표시한다. 누락·중단·기기 변경 시 오래된 값과 선을 지운다.

휴대폰 IMU와 공개 canine 센서는 수집 조건이 다르다. 공개 모델을 휴대폰에 적용하거나 개 행동 분류·건강·위험·경로 변경의 근거로 사용하지 않는다. 지도는 경로 미리보기로 유지하며 실제 GPS 추적은 추가 구현 대상이다. 기존 공개 Replay는 선택 메뉴에서 사용할 수 있다.

## 팀 휴대폰 연결

1. Mac과 휴대폰을 같은 Wi-Fi에 연결한다.
2. 휴대폰 접속을 허용한 서버가 실행되어 있어야 한다.
3. Expo 앱 Backend에 Mac의 Wi-Fi IP와8000포트를 입력한다. 휴대폰에서 localhost는 Mac 주소가 아니다.
4. 연결 적용 후 Start Streaming을 누르고 앱을 전면에 둔다.
5. 길찾기 카드의 ‘휴대폰 연결됨’과 실제 기기ID, 그래프 갱신을 확인한다.

2026-10-09 확인한 Mac 주소는172.24.22.141이다. Wi-Fi 변경 시 달라질 수 있다. 이번 실행에서 네트워크 전체 바인딩은 인증 없이 같은 네트워크 기기에 API를 노출한다는 이유로 자동 승인 검토가 차단했다. 현재 서버는127.0.0.1:8000으로 복구되어 로컬에서만 실행 중이며, 실제 팀원 휴대폰 접속은 아직 확인하지 않았다.

검증: 단위46개, 타입 검사·프로덕션 빌드 통과. 실제 FastAPI에 합성 휴대폰 프레임을 전송하는 브라우저1개와 기존Replay2개 총3개 통과. 실시간 그래프 갱신·중단 초기화·320px 넘침 없음·axe0개 확인. 합성 프레임 검증은 실제 팀원 휴대폰 접속 검증과 구분한다.
