# 시연 대시보드 UI 검증 — 2026-10-09

## 구성
- 노트북·외부 모니터 기준 3열: 음성/출발·도착 설정, 지도/경로 비교, 동행 데이터.
- 지도 위를 덮던 재생 패널을 분리하고 실시간 센서는 경로 검색 전부터 표시.
- 휴대폰 실제 센서와 공개 개 기록 Replay를 명시적으로 선택. 휴대폰에는 개 행동 AI 분류를 적용하지 않음.
- 실제 연결 상태, 마지막 수신 시간, 센서 그래프를 표시. Replay의 지도 위치는 시뮬레이션임을 유지.
- 음성 대화 기록 기본 펼침, 경로 선택/재생/분석/재검토 기능 유지.

## 검증
- TypeScript 검사, 프로덕션 빌드 성공. 단위 테스트 46개 통과.
- 브라우저 전체 25개 중 23개 통과 후 두 실패(1280px 그래프 높이, 기본 펼침으로 바뀐 대화 기록 기대값)를 수정. 관련 9개 재실행 모두 통과하여 전체 시나리오 확인.
- 1440×900, 1280×800: 지도·음성·두 실시간 센서 그래프가 화면 안에 표시됨.
- 320px: 가로 넘침 없음, axe 접근성 위반 없음.
- 경로 검색 전 센서 수신, 경로 선택 후 스트림 유지, 연결 해제 후 데이터 초기화 확인.
- Replay 재생/일시정지/재시작/내보내기, 경로 재검토, 음성 권한/연결 정리 검증.
- 자동 브라우저 테스트의 지도·경로 응답과 휴대폰 입력은 테스트 데이터. 실제 휴대폰 연결을 입증하는 자료는 아님.
- 실제 앱에서 TMAP 왕십리역 → 한양대학교병원 경로 검색: 4개 후보 중 경로 4, 896m/13분 추천 확인.
